# Worked example

Filled state for a fictional project, "Pulse", a Node service that ingests
webhooks and emails digests. It exists so you can see what good state looks like
before you write your own, and so you can judge whether your own files are
specific enough.

These are reference files. Do not copy them into a project; run `/continuum` and
let onboarding write real ones.

| File | Shows |
|---|---|
| `STATE.md` | A snapshot tight enough to inject into every session |
| `NEXT.md` | A resume contract a stranger could act on with no questions |
| `TASKS.md` | A ledger where DONE means proven |
| `brain-05-pitfalls.md` | The file that pays for the whole system |

The test for every line: would a session that read only this file do the right
thing, or would it have to ask?
