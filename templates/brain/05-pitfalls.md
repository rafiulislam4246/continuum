# Pitfalls

_pending - filled during onboarding, then grown every time something bites._

The most valuable file in the pack. Every entry is a mistake that has already
been made once, written so it is not made twice.

Format: the symptom first, because the symptom is what the next session sees.

---

### _pending_

- **Symptom:** what you observe.
- **Cause:** what is actually wrong.
- **Fix:** the specific action.
- **Added:** YYYY-MM-DD

---

Keep entries even after the underlying bug is fixed, with a note that it is
fixed and in which commit. The fix is part of the history a later session needs.
